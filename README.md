# ZR BURGER LAB - Tahap 1

Project navigasi aplikasi ZR Burger Lab menggunakan Python + Kivy.

## 9 halaman sesuai desain
1. Daftar / Sign Up
2. Beranda / Home
3. Menu Listing
4. Detail Menu
5. Keranjang / Cart
6. Checkout
7. Pembayaran Berhasil
8. Tentang Kami
9. Kontak

## Fokus Tahap 1
